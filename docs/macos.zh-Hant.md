# mjai — macOS 使用說明

[English](macos.md) · [简体中文](macos.zh-Hans.md) · 繁體中文

本套件適用 Apple Silicon Mac（M1 或更新版本）、macOS 14 以上及 Google Chrome。模型、Python 和 ONNX Runtime 均已包含。請保留完整資料夾。

## 首次使用

1. 把整個 `mjAI_portable` 資料夾複製到預定使用的位置。之後移動資料夾可能需要重新載入擴充功能。
2. 按兩下 `Start-mjai.command`，程式會檢查環境和模型。
3. 選擇 1。若尚未安裝擴充功能，在 Chrome 擴充功能頁開啟「開發人員模式」，按「載入未封裝項目」，選擇資料夾內的 `extension`。
4. 回到啟動視窗按 Enter。程式會嘗試偵測並記住擴充功能 ID；若找不到，從 Chrome 擴充功能卡片複製 ID 並貼上。
5. 保持啟動視窗開啟，使用同一個 Chrome 個人資料開啟雀魂並開始四人牌局。

舊的 Mahjong Soul AI HUD 若仍啟用，請停用舊版本，避免兩個 HUD 同時顯示。請保持舊 Tampermonkey 腳本 `Majsoul Intercept v6` 停用。

## 日常使用和 HUD

啟動程式後選擇 1，完成後在視窗按 Control–C。更換 Chrome 個人資料或移動資料夾後，可選擇 2 更新擴充功能 ID。選擇 3 可重新檢查環境。若 23410 連接埠已被其他橋接程式使用，請先關閉該橋接程式。

HUD 的「語言 / 语言 / Language」可切換繁體中文、簡體中文和 English，設定會保存在 Chrome。「最佳牌顯示」與「危險牌顯示」可獨立開關，並可選擇黑綠、白色、淺粉藍主題。

綠框標示建議。危險提示預設關閉，開啟後紅框表示高風險，橙框表示中風險。系統根據對手立直、副露、捨牌與可見牌估計風險；沒標記的牌仍可能放銃。建議牌同時危險時，綠框上會顯示對應顏色警告。

拖曳 HUD 標題可移動位置，按 −／＋ 可縮放，按 ▾ 可收合。收合時牌面標記仍會顯示。可使用「重設位置與大小」還原。若牌面標記不對齊，使用「調整標記位置」將黃色預覽框對齊第一張牌及最右操作按鈕。某些多選副露的後續選項不會被標記。

人格包括 Default、CallManiac 和 SuperTurtle。強度範圍為 0–2，預設 1；0 使用原始 Mortal 決策。CallManiac 檢查副露後的役種路線，但不能保證和牌。SuperTurtle 在立直或後盤偏向防守。設定在下次決策生效。

## 故障排除

- 沒有 HUD：確認 portable 擴充功能已在正確的 Chrome 個人資料中啟用、啟動視窗仍開啟，然後重新整理遊戲。
- 等待牌局資料：重新整理可請求重連歷史。資料缺失或不支援時可能需要等待新一局。
- 遊戲無法載入：檢查遊戲網路連線及舊攔截腳本。既有代理設定可保持開啟。
- 缺少檔案或電腦不支援：重新複製完整套件並查看環境檢查結果。若 macOS 阻擋啟動，依系統提示處理。

橋接程式預設只在本機連線，並限制已設定的擴充功能來源。擴充功能傳送牌局所需訊息，不轉送登入憑證；當前牌局歷史只保留於記憶體。開發用 Rust 原始碼與 Cargo.lock 位於 `bridge/` 和 `Mortal/`，重建需要 Rust、Python 開發環境及依賴。隨附 ONNX Runtime 1.22.0；模型來源與再分發授權需另行確認。
