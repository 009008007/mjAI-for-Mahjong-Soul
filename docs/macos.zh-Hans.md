# mjai — macOS 使用说明

[English](macos.md) · 简体中文 · [繁體中文](macos.zh-Hant.md)

本套件适用于 Apple Silicon Mac（M1 或更新版本）、macOS 14 以上和 Google Chrome。模型、Python 和 ONNX Runtime 均已包含，请保留完整文件夹。

## 首次使用

1. 将整个 `mjAI_portable` 文件夹复制到预定使用的位置。以后移动文件夹可能需要重新加载扩展程序。
2. 双击 `Start-mjai.command`，程序会检查环境和模型。
3. 选择 1。若尚未安装扩展程序，在 Chrome 扩展程序页面开启「开发者模式」，点击「加载已解压的扩展程序」，选择文件夹内的 `extension`。
4. 返回启动窗口按 Enter。程序会尝试检测并记住扩展程序 ID；若找不到，从 Chrome 扩展程序卡片复制 ID 并粘贴。
5. 保持启动窗口开启，使用同一个 Chrome 个人资料打开雀魂并开始四人牌局。

旧的 Mahjong Soul AI HUD 若仍启用，请停用旧版本，避免两个 HUD 同时显示。请保持旧 Tampermonkey 脚本 `Majsoul Intercept v6` 停用。

## 日常使用和 HUD

启动程序后选择 1，结束时在窗口按 Control–C。更换 Chrome 个人资料或移动文件夹后，可选择 2 更新扩展程序 ID。选择 3 可重新检查环境。若 23410 端口已被其他桥接程序使用，请先关闭该桥接程序。

HUD 的「語言 / 语言 / Language」可切换繁体中文、简体中文和 English，设置会保存在 Chrome。「最佳牌显示」与「危险牌显示」可独立开关，并可选择黑绿、白色、浅粉蓝主题。

绿框标示建议。危险提示默认关闭，开启后红框表示高风险，橙框表示中风险。系统根据对手立直、副露、舍牌与可见牌估计风险；没有标记的牌仍可能放铳。推荐牌同时危险时，绿框上会显示对应颜色警告。

拖动 HUD 标题可移动位置，按 −／＋ 可缩放，按 ▾ 可收起。收起时牌面标记仍会显示。可使用「重设位置与大小」还原。若牌面标记不对齐，使用「调整标记位置」将黄色预览框对齐第一张牌及最右操作按钮。某些多选副露的后续选项不会被标记。

人格包括 Default、CallManiac 和 SuperTurtle。强度范围为 0–2，默认 1；0 使用原始 Mortal 决策。CallManiac 检查副露后的役种路线，但不能保证和牌。SuperTurtle 在立直或后盘偏向防守。设置在下次决策生效。

## 故障排除

- 没有 HUD：确认 portable 扩展程序已在正确的 Chrome 个人资料中启用、启动窗口仍开启，然后刷新游戏。
- 等待牌局数据：刷新可请求重连历史。数据缺失或不支持时可能需要等待新一局。
- 游戏无法加载：检查游戏网络连接及旧拦截脚本。现有代理设置可以保持开启。
- 缺少文件或电脑不支持：重新复制完整套件并查看环境检查结果。若 macOS 阻止启动，按系统提示处理。

桥接程序默认只在本机连接，并限制已设置的扩展程序来源。扩展程序传送牌局所需消息，不转发登录凭证；当前牌局历史只保留在内存。开发用 Rust 源码与 Cargo.lock 位于 `bridge/` 和 `Mortal/`，重建需要 Rust、Python 开发环境及依赖。随附 ONNX Runtime 1.22.0；模型来源与再分发许可需另行确认。

## 选择或导入模型

选择 1 后，输入编号选择模型，或按 Enter 使用上次选择。输入 A 导入模型，将 ONNX 文件拖入终端并按 Enter。启动器会检查兼容性，并把副本保存至 `model/imported/`，保留现有模型并记住选择。输入 Q 返回。请使用自包含且兼容 Mortal v4 的 ONNX 模型。
