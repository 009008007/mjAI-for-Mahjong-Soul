# mjai — Windows 版

繁體中文 · [简体中文](windows.zh-Hans.md) · [English](windows.en.md)

這是 mjai 的 Windows x64 可攜版，包含模型、Python、ONNX Runtime、橋接程式和 Chrome 擴充功能。一般使用不需要安裝 Rust 或 Python。請保留整個資料夾，不要直接在 ZIP 內啟動。

**目前狀態：Windows x64 程式已交叉編譯，尚未在 Windows 實機測試。** 系統需求為 Windows 10／11 64 位元與 Google Chrome；實際相容性仍需在 Windows 驗證。

## 首次使用

1. 將 ZIP 解壓縮到可寫入的位置，例如「文件\\mjai」。請保留裡面的所有資料夾。
2. 安裝並開啟 Google Chrome。按兩下 `Start-mjai.bat`；若 Windows 隱藏副檔名，它可能只顯示為 `Start-mjai`。
3. 啟動視窗會檢查程式和模型。選擇 `1`，依提示打開 Chrome 擴充功能管理頁面。
4. 開啟右上角的「開發人員模式」，按「載入未封裝項目」，選擇本資料夾內的 `extension`。
5. 回到啟動視窗按 Enter。程式會嘗試自動找到擴充功能 ID；若找不到，從 Chrome 擴充功能卡片複製 ID，貼入啟動視窗。程式會記住這個 ID。
6. 保持啟動視窗開啟，使用安裝擴充功能時相同的 Chrome 使用者個人資料，重新整理雀魂網頁並開始四人牌局。右上角會顯示 mjai 的建議與風格選項。

## 之後使用

HUD 的「語言 / 语言 / Language」可切換繁體中文、簡體中文和 English，設定會保存在 Chrome。

HUD 提供「最佳牌顯示」與「危險牌顯示」兩個獨立勾選，以及黑綠、白色、淺粉藍三款主題。危險牌預設關閉。輪到自己出牌時，紅框顯示高風險牌，橙框顯示中風險牌。未立直對手若有多副露或牌局進入後段，也可能觸發橙框。和推薦牌重疊時，綠框上會顯示對應顏色的警告。

拖曳 HUD 標題可移動位置，按 −／＋ 可縮放，按 ▾ 可收合。收合時牌面標記繼續顯示。位置、大小與收合狀態由 Chrome 記住。

按兩下 `Start-mjai.bat`，選擇 `1`，保持視窗開啟並進入遊戲。要結束時，在啟動視窗按 `Ctrl+C`。

若程式更新後仍顯示舊建議，先按 `Ctrl+C` 停止，再重新開啟 `Start-mjai.bat`。如果擴充功能檔案也更新了，到 Chrome 擴充功能頁面按該擴充功能的「重新載入」，然後重新整理遊戲網頁。

如果顯示連接埠 23410 已被使用，請先關閉自己先前開啟的 mjai 啟動視窗。更換資料夾位置或 Chrome 個人資料後，可能需要重新載入擴充功能，再在啟動選單選 `2` 更新 ID。

模型建議及風格啟發式不保證正確。Windows 版尚未在 Windows 實機驗證。

## 選擇或匯入模型

選擇 1 後，輸入編號選擇模型，或按 Enter 使用上次選擇。輸入 A 匯入模型，把 ONNX 檔案拖入終端機並按 Enter。啟動器會檢查相容性，並把副本保存至 `model/imported/`，保留原有模型及記住選擇。輸入 Q 返回。請使用自包含且相容 Mortal v4 的 ONNX 模型。

## 暫時代打

勾選 HUD 的「啟用代打」後，程式會按 AI 建議操作；取消勾選即阻斷後續自動操作。通常隨機等待 1–3 秒；剩餘時間不足時，會立即執行仍與當前牌局相符的綠框建議。切牌或和牌遲遲未獲確認時，會透過 Chrome 的偵錯權限點擊目前可見的綠框。切牌時，若第一次只選中牌且雀魂仍未送出操作，會再點一次同一張牌確認。HUD 會根據牌局事件顯示確認結果。執行備援時，Chrome 可能短暫顯示偵錯提示。手動操作或可恢復的錯誤不會取消勾選；無法核對牌局時會略過該次決策。已送出的操作無法撤回。遊戲畫面需保持開啟，電腦應保持喚醒。

此功能的雀魂實局相容性仍需驗證。建議先在電腦對戰練習場測試立直與多選吃牌。
